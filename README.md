# كشكول «الذخائر والتحف» الرقمي

صفحة ويب واحدة (`index.html`) تحوّل كتاب **الذخائر والتحف** للقاضي الرشيد بن الزبير إلى كشكول رقمي للقراءة والحفظ والتأمل، مُهيّأ ل iPhone Safari و GitHub Pages.

## ما تحتويه الصفحة

- **القراءة:** ٤٦٢ بطاقة موزّعة على ١٢٥ صفحة قصيرة ضمن ١٠ أبواب/موضوعات، مع شريط الموضوعات، فهرس الصفحات، أزرار السابق/التالي، حفظ مكان القراءة، وآخر ٥ مواضع.
- **موقع ثابت:** لكل بطاقة رقم `📍 الموقع` من ١ إلى ٤٦٢ لا يتغيّر مع حجم الخط أو التمرير، مع زر للقفز إلى أي رقم.
- **الأبيات:** الأبيات بصيغة الشاملة `(الصدر ... العجز)`، مجموعّة في بطاقة قصيدة واحدة، مع محاذاة الشطرين يميناً، وعلى الجوال يُعرض كل شطر في سطر مستقل. الأبيات الناقصة معلَّمة بشارة «شطر».
- **أبيات اليوم:** ٣ اختيارات يومية ثابتة من مختاراتك، مع إمكانية إخفاء العجز للاستظهار وإظهاره باللمس.
- **مسارات القراءة:** ٦ مسارات مقترحة (بلا اختبارات أو درجات)، تتبع البطاقات المقروءة وتخفي المكتمل منها.
- **مختاراتي:** التظليلات والملاحظات، البطاقات المختارة، الأبيات المفضلة، للحفظ، محفوظة، وفوائدي.
- **بحث:** بدون تشكيل، في النص والفوائد، مع وسوم قابلة للنقر ودليل أعلام، والعودة إلى موضع القراءة نفسه.
- **أدوات المستخدم:** فائدة لكل بطاقة، تصحيح النص محلياً مع شارة «معدَّل»، تظليل النص بملاحظة وألوان، وحجم خط ١٤–٤٤ و٥ خطوط عربية.
- **تصدير:** JSON (بمعرّف الكتاب)، Markdown، Anki TSV (من الفوائد والتظليلات فقط — لا اختبارات داخل التطبيق)، وEPUB كامل يُبنى داخل المتصفح.
- **مزامنة اختيارية** عبر Gist خاص بمفتاح GitHub PAT بصلاحية `gist`، تدمج بيانات المستخدم فقط ولا تزامن الإعدادات أو موضع القراءة.

> النص الأصلي محفوظ حرفياً من المصدر؛ أي تصحيح تُدخله يُخزَّن منفصلاً ولا يعدّل النسخة الأساسية.

## المصدر

- العنوان: الذخائر والتحف — كتاب في ذكر الهدايا والتحف والنفقات في الولائم والدعوات والإعذارات والحذاقات.
- المؤلف: القاضي الرشيد بن الزبير (كما ورد في افتتاحية المصدر).
- الملف المصدري: `الذخائر والتحف.epub` (١١ قسماً: المقدمة، الأبواب ٣–١٠، والفهرس).
- النسخة: v1 — معرّف البيانات `al-dhakhair-wal-tuhaf`.

## الاستخدام على iPhone

1. افتح الرابط (أو انسخ `index.html` إلى ملفاتك وافتحه في Safari).
2. اضغط زر **مشاركة** ⬆️ ثم **إضافة إلى الشاشة الرئيسية**.
3. افتح الأيقونة من الشاشة الرئيسية لتعمل الصفحة بوضع التطبيق دون شريط Safari.

## النسخ الاحتياطي

تُحفظ الفوائد والتظليلات والتصحيحات والمختارات وموضع القراءة في `localStorage` على هذا الجهاز/Mتصفح فقط. صدّر نسخة JSON من «الإعدادات» بشكل دوري، واستعدها بالزر نفسه. لا تتزامن بياناتك بين الأجهزة إلا عبر مزامنة Gist الاختيارية.

## النشر على GitHub Pages

الأوامر التالية تُنشئ مستودعاً وتنشر الصفحة من جذر الفرع `main`:

```bash
git init
git add index.html README.md
git commit -m "Kashkol: الذخائر والتحف"
gh repo create al-dhakhair-wal-tuhaf --public --source=. --remote=origin --push
gh api repos/<owner>/al-dhakhair-wal-tuhaf/pages -X POST \
  -f 'source[branch]=main' -f 'source[path]=/'
```

ثم الرابط: `https://<owner>.github.io/al-dhakhair-wal-tuhaf/`.

إذا تعذّر استخدام `gh`، ارفع الملفين يدوياً: أنشئ مستودعاً جديداً على GitHub، ارفع `index.html` و`README.md`، ثم من **Settings → Pages** اختر **Deploy from a branch** و `main / root` واحفظ.

## التحقق

- جميع المعرّفات فريدة، والمواقع ١..٤٦٢ بلا فجوات.
- أكبر بطاقة ٢٢٧٧ حرفاً وأكبر صفحة فرعية ٣٤٨٥ حرفاً (ضمن حد ٣٥٠٠ للجوال).
- فحص `node --check` لكل كتل JavaScript ناجح، ولا يظهر النص `undefined` في أي تبويب.
- توقيع ZIP لملف EPUB المُصدَّر: `PK\x03\x04` مع عدد الملفات المتوقع.
